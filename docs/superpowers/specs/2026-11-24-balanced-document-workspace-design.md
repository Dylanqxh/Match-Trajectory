# 均衡文档工作台设计

## 目标

修复桌面端“并排查看”中编辑表单过窄的问题，让编辑区具备可连续填写的宽度，同时保留专注预览和专注编辑两种既有模式。

## 现状与约束

- 当前 1234px 窗口下，工作台画布约 900px，编辑栏被固定在 320px，表单有效宽度约 255px。
- 编辑、预览、核对和保存行为保持不变；不新增拖拽分栏或自动切换模式。
- 桌面并排模式优先保证编辑栏至少 400px；预览仍占剩余空间。
- 当窗口不足以同时容纳 400px 编辑栏、430px 预览栏和间距时，提前切换为单列，避免横向溢出。
- 专注预览继续最大化 A4 页面，专注编辑继续使用全宽编辑区。
- 不处理或引入图片、音频、视频功能。

## 方案比较

1. **固定加宽编辑栏**：改动小，但在不同窗口下容易再次偏向一侧。
2. **可拖拽分栏**：自由度高，但需要持久化、键盘无障碍和更多状态管理，本轮成本不成比例。
3. **响应式均衡分栏（采用）**：编辑栏使用带最小宽度的比例轨道，空间不足时切为单列；与现有三种视图模式配合，复杂度最低。

## 验收

- 桌面并排布局不再使用 290–320px 的编辑栏上限，编辑栏最小宽度为 400px。
- 预览栏最小宽度为 430px，并继续消耗剩余空间。
- 1180px 及以下进入单列工作台规则，避免两栏最小宽度互相挤压。
- 当前前端测试、类型检查和生产构建通过。
