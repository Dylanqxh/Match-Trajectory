# 文档预览空间优化设计

## 意图

让简历整页预览成为文档工作区的真正主视觉，避免顶部的核对入口和视图切换占用整行宽度，同时保留随时切换编辑、预览和并排模式的能力。

## 目标

- 将“逐项核对与修正”和“并排查看 / 专注预览 / 专注编辑”统一放入左侧控制区。
- 默认并排模式使用紧凑固定左栏，把剩余宽度优先交给右侧预览。
- 专注预览隐藏编辑表单但保留窄左侧控制区，避免无法切回其他视图。
- 文档工作区默认折叠右侧 Agent；用户主动展开后保持本次选择。
- 没有 AI 审阅信息时不显示空的核对入口。
- 保持现有审阅弹窗、保存、导出、预览渲染和移动端单列行为不变。

## 非目标

- 不改动简历内容模型、审阅状态或导出逻辑。
- 不修改 Agent 对话功能、全局导航或预览文档本身。
- 不新增图片、音频、视频能力或新的 UI 依赖。

## 方案比较

### 方案 A：只缩小顶部横栏

改动最少，但顶部仍跨越预览宽度，“逐项核对与修正”仍会把预览向下挤。不能解决主要问题。

### 方案 B：把所有控件放进编辑面板

并排模式可用，但专注预览会隐藏编辑面板，用户无法切回其他模式。可用性风险不可接受。

### 方案 C：左侧常驻控制区加可隐藏编辑区（采用）

左侧区域由常驻控制卡和编辑表单组成。并排模式显示两者；专注预览只保留紧凑控制卡；专注编辑隐藏右侧预览并扩展左侧。该方案直接扩大预览，同时维持完整导航能力。

## 布局与行为

- 新增 `DocumentWorkspaceControls`，显示当前简历名称、保存状态、视图切换和可选核对入口。
- `App` 中移除跨栏的 `review-entry` 与 `document-workspace-bar`，把控制组件放在 `.document-left-pane` 顶部。
- 并排模式的左栏采用约 320px 的紧凑宽度，右栏占据其余空间。
- 专注预览模式的左栏缩为约 230px，只保留控制卡；编辑表单隐藏。
- 专注编辑模式为单栏，右侧预览隐藏。
- 进入文档工作区时，Agent 在没有用户显式选择的情况下保持折叠，释放约 274–324px；用户仍可从折叠条展开。
- 980px 以下继续使用单列布局，并确保视图按钮可横向完整显示。

## 验收

- 核对入口与三个视图按钮都位于左侧控制区，预览上方不再存在跨栏控制条。
- 专注预览时仍能看到三个视图按钮并切回并排或编辑。
- 默认并排模式下右侧预览宽度明显大于此前按比例分栏的布局。
- 约 1234px 宽的桌面窗口中，专注预览不应因默认展开的 Agent 侧栏缩到约 380px。
- 无 AI 信息的简历不显示核对入口。
- 现有前端测试、TypeScript 检查和生产构建通过。
