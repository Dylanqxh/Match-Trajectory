# 事实审阅避免误判

日期使用宿主 reference_date，不用知识截止时间；无可靠基准只提醒。年限允许保守取整，不要求精确到月。
“负责某模块”有明确原文依据，不因其他事项写“参与”而推翻；它也不等于独立负责整个项目。
允许等义压缩、更保守的措辞与删除未验证的分数目标；目标不能写成已实现的效果。审阅语义，不要求逐字复制。
负面句（已下线、未推广、他人完成、试运行后停止）被照搬是写作问题，应删或压成「本人负责 X」，不要要求把否定句补回去。把试运行写成上线、把了解写成熟悉、把 Spring 写成 Spring Boot、把一个项目写成两个项目，才是事实阻断。
无依据事实、直接冲突、责任或范围升级才阻断。“可能”“想了解更多”、缺数字、岗位差距或文风一般只作相应提醒或质量意见。原文里的获奖和获评被删掉，要按质量要求补回，不能当成可有可无。
原文已支持的事实不要求重复证明，表达不清则按质量提出可执行修改；不要把写作问题藏在事实 pass 后面。
